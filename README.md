# Toronto Aerosport website

React + Vite site. Run locally: `npm install` then `npm run dev`.

- Words and prices: `src/data/siteData.js` and `src/data/learnData.js`
- Photos: `public/images/` (hero.jpg, learn.jpg, plane.jpg, cost.jpg, cockpit.jpg)
- Deploys to GitHub Pages automatically when you push to `main`.
