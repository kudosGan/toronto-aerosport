# Student Corner: one-time setup

1. Supabase -> SQL Editor -> New query. Paste `supabase/student-corner.sql`, change `YOUR-TEAM-EMAIL@example.com`
   to the email of your team login, Run. Then paste `supabase/student-corner-2.sql` in a new query and Run (no edits needed).
   Then paste `supabase/student-corner-3.sql` (logbook fields) and Run. Do all three BEFORE pushing the new site.
2. To add a student: Student Corner -> sign in with the team email and password -> enter the full name and the access end date -> Add student.
   The site makes the ID (TAS-001, TAS-002...) and the login. For now the password is the student's full name.
3. Students sign in at `#student-corner` with their student ID and password.
4. To end access early use **End access**. To extend, change the date and click **Save date**. Access also stops by itself on the end date.

Logbooks are never deleted when access ends.
